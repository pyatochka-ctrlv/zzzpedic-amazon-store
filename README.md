# ZzzPedic — Amazon Brand Store Concept

Статична одностор inkова HTML-сторінка. Готова до деплою на GitHub Pages.

## Деплой на GitHub Pages

1. Створіть новий репозиторій на GitHub (або використайте існуючий).
2. Завантажте вміст цього архіву в корінь репозиторію (файл `index.html` має лежати в корені або в папці `/docs`).
3. У репозиторії перейдіть в **Settings → Pages**.
4. У розділі **Source** оберіть гілку (наприклад `main`) і папку (`/root` або `/docs`).
5. Збережіть — GitHub видасть посилання виду `https://<username>.github.io/<repo>/`.

Сторінка не потребує збірки — це чистий HTML/CSS/JS, зображення та відео підключені через зовнішні посилання (Cloudinary), тому додаткових файлів не потрібно.
